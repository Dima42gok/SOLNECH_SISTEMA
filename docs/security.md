# Безопасность и роли доступа

Система AccessEvent использует ролевую модель доступа.

## Роли

| Роль | Права |
|------|-------|
| guest | Просмотр списка мероприятий и главной страницы |
| user | Регистрация на мероприятия, отмена записи, отзывы, оповещения |
| organizer | Создание и редактирование своих мероприятий, просмотр списка участников |
| admin | Управление пользователями, категориями и всеми мероприятиями |

## Защита данных

- Пароли хранятся только в виде хеша.
- Секретные ключи и настройки лежат в файле .env и не попадают в репозиторий.
- Доступ к страницам проверяется по роли пользователя на сервере.
