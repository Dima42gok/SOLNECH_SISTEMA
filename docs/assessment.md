# Оценка ИС AccessEvent

## SWOT-анализ

| | Плюсы | Минусы |
|---|---|---|
| Внутреннее | Силы: инклюзивность на уровне архитектуры; автоматические тесты в CI; контейнеризация | Слабости: нет push-уведомлений; тесты на SQLite, а продакшен на PostgreSQL |
| Внешнее | Возможности: рост аудитории за счёт инклюзивности; интеграция с календарями | Угрозы: конкуренты с мобильными приложениями; утечка данных |

## Вывод о готовности к опытной эксплуатации
Система готова к опытной эксплуатации в ограниченном контуре: основные функции реализованы и покрыты тестами, развёртывание автоматизировано. Перед публичным запуском требуется: аудит безопасности, нагрузочное тестирование и переход тестов на PostgreSQL.

## Направления модернизации

### 1. Push-уведомления о старте мероприятия
Технологии: Service Worker, VAPID-ключи. Для слабослышащих: визуальные push вместо звуковых.

### 2. Интеграция с календарём
Технологии: генерация .ics-файла на сервере. Для слабослышащих: не пропустить начало без аудио-сигналов.

### 3. Автоматические субтитры для видео
Технологии: Whisper или облачные API распознавания речи. Для слабослышащих: прямой доступ к содержанию трансляций.

### 4. Мобильное приложение (PWA)
Технологии: Service Worker, офлайн-кеш. Для слабослышащих: уведомления и чат с телефона.
