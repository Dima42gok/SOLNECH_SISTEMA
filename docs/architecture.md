# Архитектура системы AccessEvent

Приложение построено по классической трёхслойной схеме.

## Слои

- **Представление:** HTML-шаблоны Jinja2 и Bootstrap, адаптивная вёрстка.
- **Логика:** Flask, маршруты разделены по модулям: auth, events, registrations.
- **Данные:** SQLAlchemy и реляционная база данных PostgreSQL.

## Развёртывание

Приложение упаковано в Docker-образ. Контейнеры запускаются через docker-compose.
Сборка и публикация образа выполняются автоматически через GitHub Actions.

## Структура проекта

Каталоги: routes, templates, static, utils, docs. Конфигурация находится в config.py.
