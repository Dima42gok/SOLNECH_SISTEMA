# Требования к системе AccessEvent

## User Stories

- Как пользователь, я хочу зарегистрироваться на сайте, чтобы получить доступ к мероприятиям.
- Как пользователь, я хочу войти в систему, чтобы управлять своими записями.
- Как пользователь, я хочу просматривать список мероприятий, чтобы выбрать подходящее.
- Как пользователь, я хочу фильтровать события по доступности, чтобы найти удобные для себя.
- Как пользователь, я хочу записаться на мероприятие, чтобы участвовать в нём.
- Как пользователь, я хочу отменить запись, чтобы освободить место для других.
- Как организатор, я хочу создавать мероприятия, чтобы привлекать участников.
- Как организатор, я хочу указывать наличие сурдоперевода, чтобы гости знали об условиях.
- Как организатор, я хочу видеть список записавшихся, чтобы планировать площадку.
- Как пользователь, я хочу получать визуальные оповещения, чтобы не пропустить важные события.
- Как администратор, я хочу управлять пользователями, чтобы поддерживать порядок на платформе.

## Нефункциональные требования

- NFR-1: Страницы загружаются не дольше 3 секунд при обычной нагрузке.
- NFR-2: Интерфейс соответствует рекомендациям доступности WCAG 2.1 уровня AA.
- NFR-3: Пароли хранятся только в виде хеша.
- NFR-4: Интерфейс корректно отображается на телефоне и на компьютере.
- NFR-5: Система запускается в Docker одной командой.
