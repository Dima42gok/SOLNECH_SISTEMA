# AccessEvent

Инклюзивная платформа мероприятий.

AccessEvent — веб-платформа для организации мероприятий с акцентом на доступность
для людей с нарушениями слуха. Организаторы создают мероприятия, участники
регистрируются на них, получают визуальные уведомления (цветные баннеры)
и общаются через текстовый чат.

## Технологии

- Python 3.10+ и Flask 2.3+
- PostgreSQL 14+
- Jinja2
- GitHub Actions и GitHub Container Registry (GHCR)
