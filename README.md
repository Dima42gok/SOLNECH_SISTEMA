# Симуляция Солнечной системы

Трёхмерная модель Солнца и восьми планет на Python и Ursina.
Размеры и расстояния условные, относительные периоды обращения приближены к реальным.

## Запуск

```sh
cd /Users/kirrrkaz/Desktop/accessevent
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python solar_3d.py
```

Управление камерой: правая кнопка мыши — поворот, колесо — масштаб,
средняя кнопка мыши — перемещение. Ползунок внизу меняет скорость времени.
Для выхода закройте окно.
